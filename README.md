# STM32 Bare-Metal Peripheral Drivers

A collection of bare-metal peripheral drivers for STM32 microcontrollers, written in C using direct register access and official hardware documentation, without relying on HAL libraries.

## Peripherals

- GPIO (General-Purpose Input/Output)
- ADC (Analog-to-Digital Converter)
- UART (Universal Asynchronous Receiver/Transmitter)
- Timers
- DMA (Direct Memory Access)
- SPI (Serial Peripheral Interface)
- I2C (Inter-Integrated Circuit)
- RTC (Real-Time Clock)

## Future Plans

The goal is to reuse and integrate these drivers into a future embedded systems project, applying them in a practical hardware application.

## Status

Work in progress — drivers are being implemented and tested incrementally.
